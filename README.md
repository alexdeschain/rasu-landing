# РАСУ — лендинг

Современный одностраничный сайт для РАСУ (автоматизированные системы управления для энергетики).
Чистый HTML/CSS/JS + Three.js (3D-сцена подстанции со «снятием крыши»). Статика, разворачивается на GitHub Pages.

## Локальный запуск
```
python3 -m http.server 8000
```
Открыть http://localhost:8000
